NetSplit UI 重构方案选择

共 4 套方案，悬停预览，点击查看完整效果

方案 A · Dashboard 仪表盘 信息密度高
保留左侧导航，顶部突出状态大卡片，4个关键指标横排展示，整体以卡片网格布局为主。适合需要一屏看全所有信息的用户。
方案 B · Command 指挥台 沉浸感强
深色为主，顶部导航栏替代侧边栏，全宽状态条始终可见，内容区使用大字号关键数据展示。适合喜欢简洁专注风格的用户。
方案 C · Minimal 极简 轻量干净
去掉侧边栏，改用图标 Tab 导航，整体留白大，只突出最核心的状态与操作。适合追求简洁、不需要同时查看多模块的用户。
方案 D · Split 分栏固定 状态始终可见
左栏固定显示实时状态（网卡、节点、流量）、右栏切换功能页，两栏始终同时可见。适合需要随时看实时数据又要操作配置的重度用户。
