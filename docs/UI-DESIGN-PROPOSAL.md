# NetSplit UI 设计方案

## 一、设计目标

为 NetSplit 双网卡透明分流工具打造一个现代、直观、高效的用户界面，让复杂的网络配置变得简单易用。

### 核心原则
- **安全第一**：清晰展示系统状态，防止误操作
- **简约直观**：减少学习成本，突出核心功能
- **实时反馈**：网络状态、流量监控可视化
- **渐进式披露**：将复杂配置隐藏在高级选项中

### 2.2 托盘图标设计

**状态指示**：
- 🟢 绿色盾牌：分流已启用，运行正常
- 🟡 黄色盾牌：警告状态（网卡异常、代理连接不稳定）
- 🔴 红色盾牌：分流已禁用或严重错误
- ⚪ 灰色盾牌：服务未连接

**右键菜单**：
```
net-split - 分流运行中
─────────────────────
√ 开启分流 / 关闭分流
代理节点 ›  [节点列表]
─────────────────────
打开控制台
修复运行状态
─────────────────────
退出界面
```

## 五、交互设计细节

### 5.1 动画效果

**页面切换**
- 淡入淡出 + 轻微位移
- 持续时间: 200ms
- 缓动函数: cubic-bezier(0.4, 0.0, 0.2, 1)

**加载状态**
- 骨架屏占位
- 旋转加载指示器
- 进度条（长时间操作）

**状态反馈**
- 按钮点击: 轻微缩放 (scale 0.98)
- 卡片悬停: 阴影加深

### 7.1 UI 框架选择

**推荐方案 1: WinUI 3 (Windows App SDK)**
- ✅ 现代化的 Fluent Design
- ✅ 原生性能
- ✅ 深色主题内置支持
- ✅ 丰富的控件库

- ✅ 快速迭代
- ✅ 使用自定义绘制实现现代化外观
- ⚠️ 需要手动实现更多细节

**推荐方案 3: Avalonia UI**
- ✅ 跨平台（未来可扩展）
- ✅ 现代 XAML 语法
- ✅ 丰富的样式系统
- ⚠️ 需要重写 UI

- 自绘制 GDI+ (WinForms)

- 防抖/节流（搜索框、实时更新）

## 附录

### A. 现有 UI 问题分析

基于代码分析，当前 WinForms 实现存在的问题：

1. **视觉风格陈旧**: 使用传统 WinForms 控件，缺乏现代感
2. **状态反馈不足**: 用户不清楚系统当前在做什么
3. **错误提示不友好**: 技术性错误信息直接暴露给用户
4. **布局不够灵活**: 固定布局难以适配不同屏幕尺寸
5. **缺乏可视化**: 流量、连接等信息缺少图表展示

### B. 竞品参考

- **Clash Verge**: 现代化的 Clash GUI，Tauri + Vue 技术栈
- **V2RayN**: 简洁实用的 V2Ray GUI
- **Proxifier**: 专业的代理管理工具
- **Microsoft Edge 设置页**: Windows 11 原生设计风格参考
