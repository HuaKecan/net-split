# net-split UI 设计方案（WinForms 重设计）

> 目标：把现有 `NetSplit.Tray` 的 WinForms 界面重做为一套克制、可信、信息清晰的现代扁平界面。
> 交付边界：**只改 UI 层**（`MainForm`、`TrayApplicationContext`，新增 `Theme` 主题系统与一组自绘控件）。
> **服务与 Named Pipe RPC 契约、`RpcCommands`、`Models` 完全不动。** 复用现有 `NamedPipeRpcClient` 逐页接线。

---

## 0. 范围与约束

- 技术栈：保持 **WinForms + GDI+ 自绘扁平控件**，不引入 WPF / WinUI3 / WebView。
  - 理由：后端（LocalSystem 服务 + Named Pipe RPC）已稳定，UI 是薄客户端，重写 UI 层风险最低。
- 双主题：深色 / 浅色，默认跟随系统。同一套视觉词汇。
- 复用的现有能力：`RpcCommands.Discover / GetStatus / GetSettings / GetLogs / Validate / Enable / Disable / Repair / Rollback / RefreshSubscriptions / SelectProxy / UpdateBindings / AddSubscription / RemoveSubscription / AddRule / RemoveRule`，以及 `ClashVergeDiscovery.FindCurrentProfilePath`。

---

## 1. 设计定位

**场景句（决定配色与明暗）：**

> 用户是日常国内办公、需要稳定访问国内外网站的技术型用户。工具常驻托盘，白天在办公室、晚上在书房打开面板看状态、切节点。它必须让用户**一瞥就能回答「分流是否正常、出口在哪」**，然后退到后台——不打扰、不炫技。

由此得出：

- **克制配色（Restrained）**：1 个主色（teal，传达「连接 / 链路」）+ 中性色 + 语义色（成功 / 警告 / 危险）。
- 主色只用于**主操作、当前选中、状态指示**，绝不作装饰。
- 默认跟随系统明暗。

> 正文 `text-primary` / `text-secondary` 均 ≥ 4.5:1。

### 2.2 间距 / 圆角 / 字号（Primitive）

- **间距**（4px 网格）：`4 / 8 / 12 / 16 / 20 / 24 / 32`。
- **圆角**：`4`（小控件）/ `6`（输入、按钮）/ `8`（卡片）/ 全圆（pill、开关、badge）。
  - **卡片最大 8px，禁止 24 / 28 / 32 大圆角。**
- **字号**（固定比例，非流式）：`11`（badge）/ `12`（caption、表格）/ `13`（正文）/ `14`（强调正文）/ `17`（页标题）/ `20`（指标数字）。
  - 指标数字、IP、端口、延迟、速率用**等宽数字（tabular figures）**。
- **字族**：单一字体族 **Segoe UI Variable**（Win11）→ 回退 **Segoe UI**；日志 / 端口 / IP 用 **Cascadia Mono** → 回退 Consolas。

## 4. 页面规格

### 4.1 概览（首页）

```
┌─ 状态卡 ─────────────────────────────────────────────────────┐
│ [●] 分流正常                        TUN 已启用 · 节点 hk01 · 42ms │
│                                                              │
│  应用流量 ──▶ [TUN] ──▶ 国内 ──▶ 网卡1（主宽带）            │  ← 链路示意
│                        └─▶ 国外 ──▶ 节点 ──▶ 网卡2（F50）      │      (当前路径高亮)
│                                                              │
│  操作： [校验] [修复] [回退配置] [刷新]                         │
└──────────────────────────────────────────────────────────────┘

┌─ 网卡1 · 国内直连 ──┐   ┌─ 网卡2 · 代理出口（F50 候选）──┐
│ ● 在线              │   │ ● 在线                          │
│ 以太网 192.168.6.2  │   │ F50 192.168.0.163               │
│ 网关 192.168.6.1    │   │ 网关 192.168.0.1                 │
│ ↓ 1.2 MiB/s ↑ 128 B/s│  │ ↓ 0 B/s ↑ 0 B/s   [sparkline]  │
└─────────────────────┘   └─────────────────────────────────┘

┌─ 当前节点 ────────────────────────────────────────────────┐
│ hk01 [SS] · 42ms · 由 NETSPLIT-AUTO 自动选择      [切换节点] │
└───────────────────────────────────────────────────────────┘
```

**关键点：**

- **链路示意（FlowDiagram）**是本页核心——用一条静态流程图让「分流」可被理解。
  - 当前激活分支（国内 / 国外）用 `accent` 高亮；故障分支用 `danger` + 断开样式。
  - 这是全应用唯一一个「delight 时刻」，其余页面保持克制。
- 两张网卡卡是**对称数据卡**（允许），但用**标签色 + 图标区分**（网卡1＝国内直连、网卡2 显示「F50 候选」标识），避免「一模一样的卡片网格」。
- 状态徽章颜色映射 `RuntimeMode`（见 §7）。

### 4.2 节点

```
┌───────────────────────────────────────────────────────────────┐
│ 策略：[NETSPLIT-AUTO 自动选择 ▾]   [测速全部]  [🔍 搜索节点]    │

│   ○ us03   [Trojan] 128 ms             [测速]                  │
│ ▾ 订阅 B (5)                                                     │
│   ○ ...                                                          │
└───────────────────────────────────────────────────────────────┘
```

- 协议 badge（`SS` / `VMess` / `Trojan` / `Hysteria2`…）用等宽小 pill。
- 延迟分级着色：`<60ms` success / `<150ms` text-secondary / `≥150ms` warning / 超时 danger。
- 点击行 = 切到该节点（`SelectProxy`）；顶部下拉切回「自动选择」（`NETSPLIT-AUTO`）。
- **空态**：`还没有节点 → 去「订阅」页添加或导入`（带跳转按钮）。

## 7. 状态映射（`RuntimeMode` → 视觉）

| 模式 | 徽章文字 | 圆点色 | 说明 |
|---|---|---|---|
| `Healthy` | 分流正常 | `success` | 主开关亮、链路全绿 |
| `Disabled` | 已关闭 | `text-muted` | 主开关灰 |
| `Starting` / `Stopping` | 启动中 / 停止中 | `warning` | 顶栏进度条 |
| `DirectUnavailable` | 主宽带不可用 | `warning` | 网卡1 卡变 amber，链路国内分支断开 |
| `ProxyUnavailable` | F50/代理不可用 | `danger` | 网卡2 卡变红，链路国外分支断开 |
| `CoreUnavailable` | Mihomo 不可用 | `danger` | 全局 banner + 重试 |
| `Misconfigured` | 配置异常 | `danger` | banner 列出错误项 |

## 8. 交互与状态规范

1. **异步动作**：点击后立刻禁用相关按钮 → 顶栏 2px 进度条（150–250ms 过渡）→ 成功 / 失败用 `InlineBanner` 内联反馈。
   - **不弹 MessageBox**，唯一例外：高危操作（如「开启分流会改变网络路径」）保留一次确认。
2. **服务离线**（Named Pipe 失败）：全局 banner `服务离线，点击重试`；所有写操作禁用，只读状态保留最后快照。
3. **加载态**：页面数据用占位（skeleton：灰块替代数字 / 行），不是居中转圈。
4. **空态**：每个列表都有「教你怎么做」的空态（见 §4）。
5. **一致性**：所有「保存 / 应用 / 添加 / 删除」用同一套按钮形状与文案；危险操作统一 `danger` + 确认。

---

## 9. 无障碍与细节

- 正文 / 次要文字对比度 ≥ 4.5:1，占位文字同样达标（已在上表取深一档的 `text-muted`）。
- 状态**不单靠颜色**：每个状态点配文字标签；徽章文字 + 圆点 + 图标三者并用。
- 所有图标按钮带 `ToolTip`；支持键盘 Tab 顺序；焦点态用 `border-strong` 外框。
- 等宽数字用于 IP、端口、延迟、速率，避免数值跳动。

## 10. 给 Codex 的实现顺序

1. **主题层**：`UiTheme`（色表）+ `UiMetrics`（间距 / 圆角 / 字号）+ `ThemeProvider`（读系统深色注册表，跟随切换）。
2. **基础控件**：按钮 4 类、`ToggleSwitch`、`ModeBadge`、`InlineBanner`、`EmptyState`、深色表单适配。
3. **外壳**：侧栏导航 + 顶栏（状态徽章 + 主开关）+ 页面切换。
4. **各页**：概览（含 `FlowDiagram` + `AdapterCard` + sparkline）→ 节点 → 订阅 → 规则 → 日志 → 设置。
5. **托盘菜单**重做。
6. **接线**：复用现有 `NamedPipeRpcClient` + `RpcCommands`，逐页绑定 `GetStatus / Discover / GetSettings / GetLogs / ...`。
7. **状态与空态**收尾 + 双主题回归。
